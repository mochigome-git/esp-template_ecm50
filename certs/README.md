# Certificates (`certs/`)

Place your TLS certificate files here. They are flashed to the **SPIFFS**
partition and read at runtime from `/spiffs/certs/`.

## Required files (depending on `SSL_MODE` in `config.h`)

| File         | Used when            | Description                        |
| ------------ | -------------------- | ---------------------------------- |
| `ca.pem`     | `server` or `mutual` | Broker CA certificate (PEM format) |
| `client.crt` | `mutual` only        | Client certificate (PEM format)    |
| `client.key` | `mutual` only        | Client private key (PEM format)    |

## EMQX

```bash
# Self-signed CA (generated by EMQX or your own PKI)
cp /path/to/emqx/certs/ca.pem      certs/ca.pem
cp /path/to/emqx/certs/client.pem  certs/client.crt
cp /path/to/emqx/certs/client.key  certs/client.key
```

EMQX Dashboard → Listeners → SSL → `cacertfile`, `certfile`, `keyfile` for the
server side. The `client.crt` / `client.key` pair here are the **device**
credentials.

## Mosquitto

```bash
# Mosquitto CA and device cert generated with mosquitto_passwd or openssl
cp /etc/mosquitto/ca_certificates/ca.crt  certs/ca.pem
cp /etc/mosquitto/certs/device.crt        certs/client.crt
cp /etc/mosquitto/certs/device.key        certs/client.key
```

`mosquitto.conf` server side:

```
listener 8883
cafile   /etc/mosquitto/ca_certificates/ca.crt
certfile /etc/mosquitto/certs/server.crt
keyfile  /etc/mosquitto/certs/server.key
require_certificate true   # for mutual TLS
```

## Flash certs to SPIFFS

```bash
# 1. Install mkspiffs (once)
pip install esp-idf-size   # already available in IDF env

# 2. Build the SPIFFS image
python "C:\esp\v6.0.1\esp-idf\components\spiffs\spiffsgen.py" 262144 certs spiffs.bin

# Or use the IDF helper (auto-detects partition size from partitions.csv):
python $IDF_PATH/components/spiffs/spiffsgen.py 262144 certs spiffs.bin

# 3. Flash to the spiffs partition
esptool.py --port COM7 write_flash 0x210000 spiffs.bin
 or
python -m esptool --chip esp32s3 --port COM7 --baud 460800 write-flash 0x187000 spiffs.bin
# (Offset is printed by `idf.py partition-table` under the "spiffs" row)
```

> **Tip:** You can also use `idf.py flash` after adding the SPIFFS image as a
> component — see `CMakeLists.txt` for the `spiffs_create_partition_image` call.

## SSL_MODE = "none" (plain MQTT, no TLS)

Leave this folder empty and set in `config.h`:

```c
#define USE_SSL   false
#define SSL_MODE  "none"
```

The broker port will automatically use `PORT_MQTT` (1883).
